
# RAG Module

## Mục đích
Truy xuất tài liệu pháp luật phù hợp với câu hỏi người dùng.

## Nhiệm vụ
- Thu thập và làm sạch dữ liệu.
- Chia tài liệu thành các đoạn (chunking).
- Tạo embedding.
- Lưu trữ và truy xuất vector bằng Qdrant.
- Trả về nội dung và nguồn tài liệu liên quan.

## Người phụ trách
Hiền.

## Trạng thái
Đang chuẩn bị cấu trúc.
