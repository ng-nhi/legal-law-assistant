
# Agent Module

## Mục đích
Điều phối quy trình xử lý câu hỏi pháp luật.

## Nhiệm vụ
- Nhận câu hỏi và ngữ cảnh truy xuất.
- Điều phối các bước xử lý theo thiết kế.
- Kết hợp kết quả từ RAG.
- Phối hợp với Citation Validator.
- Trả về kết quả cho Backend.

## Người phụ trách
Ánh.

## Trạng thái
Đang chuẩn bị cấu trúc.
