
# Backend Application

## Mục đích
Thư mục này dành cho phần ứng dụng backend của Legal Law Assistant.

## Trách nhiệm dự kiến
- Tiếp nhận yêu cầu từ frontend.
- Kiểm tra dữ liệu đầu vào.
- Gọi các thành phần RAG hoặc Agent khi đã được tích hợp.
- Trả kết quả theo định dạng API thống nhất.
- Xử lý lỗi và ghi log phù hợp.

## Lưu ý triển khai
Cấu trúc mã nguồn, các endpoint và cách chạy phải được cập nhật theo code thực tế. Không mô tả endpoint là đã hoạt động nếu chưa triển khai và kiểm thử.
